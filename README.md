# FreekiCAD
<img src="Resources/icons/FreekiCAD.png" alt="Logo" width="64" height="64">

FreekiCAD bridges KiCad and FreeCAD. It supports:

- Importing KiCad PCB files
- Editing board outlines
- Bending flexible PCBs
- Assembling multiple PCBs and STEP models
- Importing and exporting `.kkkk_asm` files

STEP imports in FreekiCAD are symbolic and reloadable, making FreekiCAD useful
even without KiCad. For example, it can be used to create assemblies from
multiple STEP models.
